❓ الأسئلة بـ (هل) - Yes/No Questions
💡 هل + جملة = سؤال (نعم/لا)
🔄 (1) حول الجمل إلى أسئلة - Turn into questions
1) هذا كرسي. → ؟
This is a chair. → Question?
✅ الإجابة:
هل هذا كرسي؟
Is this a chair? – "hal haatha kursee?"
2) هذه صورة. → ؟
This is a picture. → Question?
✅ الإجابة:
هل هذه صورة؟
Is this a picture? – "hal haathihi soora?"
3) هذا سرير. → ؟
This is a bed. → Question?
✅ الإجابة:
هل هذا سرير؟
Is this a bed? – "hal haatha sareer?"
4) هذه خزانة. → ؟
This is a cupboard. → Question?
✅ الإجابة:
هل هذه خزانة؟
Is this a cupboard? – "hal haathihi khizaana?"
5) هذا تلفزيون. → ؟
This is a TV. → Question?
✅ الإجابة:
هل هذا تلفزيون؟
Is this a television? – "hal haatha television?"
💬 (2) أجب بـ (نعم) أو (لا) - Answer Yes or No
1) هل هذا قلم؟ (الإجابة: نعم)
Is this a pen? (Yes)
✅ الإجابة:
نعم، هذا قلم.
Yes, this is a pen. – "na'am, haatha qalam"
2) هل هذه سيارة؟ (الإجابة: لا - دراجة)
Is this a car? (No - bicycle)
✅ الإجابة:
لا، هذه دراجة.
No, this is a bicycle. – "la, haathihi darraaja"
3) هل هذا باب؟ (الإجابة: لا - شباك)
Is this a door? (No - window)
✅ الإجابة:
لا، هذا شباك.
No, this is a window. – "la, haatha shubbaak"
4) هل هذه صورة؟ (الإجابة: نعم)
Is this a picture? (Yes)
✅ الإجابة:
نعم، هذه صورة.
Yes, this is a picture. – "na'am, haathihi soora"
5) هل هذا مفتاح؟ (الإجابة: لا - خاتم)
Is this a key? (No - ring)
✅ الإجابة:
لا، هذا خاتم.
No, this is a ring. – "la, haatha khaatim"
🔍 الأسئلة بـ (أين) - Where Questions
💡 أين = where (للسؤال عن المكان)
🛏️🪟🪑📺
في الغرفة: السرير بجانب الشباك. الكرسي بين المائدة والخزانة. التلفزيون فوق الخزانة. الصورة بجانب الشباك. الباب بجانب الخزانة.
In the room: The bed is beside the window. The chair is between the table and the cupboard. The TV is above the cupboard. The picture is beside the window. The door is beside the cupboard.
